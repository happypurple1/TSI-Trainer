# TSI Strategy Trainer

A browser-based practice tool for the **Texas Success Initiative Assessment (TSIA2)** — a single, self-contained HTML page for strategy and question practice. No install, no dependencies.

## Use it

Open `index.html` in any browser. To share a live link, enable **GitHub Pages** on this repo (Settings → Pages → deploy from `main`), which will publish it at `https://happypurple1.github.io/TSI-Trainer/`.

## Built for

Students preparing for the TSIA2 across the reasoning areas it assesses. Companion to the practice materials in [`tsi-prep-materials`](https://github.com/happypurple1/tsi-prep-materials).
